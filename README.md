# 動画投稿ツール（案内ページ）

所有者本人が自分のYouTubeチャンネルへ動画を投稿し、動画情報や再生数などの統計を確認するための**個人用ツールについての案内ページ**を保管するリポジトリです。

## 収録ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | ツールの目的とプライバシーポリシーへのリンクを掲載する案内ページ |
| `privacy.html` | YouTube APIサービスを利用する際の情報の扱いを説明するプライバシーポリシー |

このリポジトリにあるのは上記のHTMLページです。**動画のアップロード処理やYouTube APIとの通信を行うアプリ本体のコードは含まれていません。**

## ページの確認方法

`index.html` をブラウザで開くと概要を確認できます。「プライバシーポリシー」から `privacy.html` へ移動できます。

HTMLとCSSだけで構成されており、ページ表示のためのビルドや依存パッケージのインストールは不要です。

## プライバシー・利用範囲

[プライバシーポリシー](privacy.html)には、Googleアカウントで許可された範囲での動画アップロード・情報取得、情報の保存方法、アクセス権の取り消し方法などを記載しています。

ページは検索エンジン向けの `noindex` を指定していますが、これはアクセス制限ではありません。公開する場合は、実際のツールの処理とプライバシーポリシーの記述が一致することを別途確認してください。
