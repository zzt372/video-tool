プライバシーポリシー

この動画投稿ツール（以下「本ツール」）は、所有者本人だけが使う個人用のツールです。

使う情報

本ツールは、利用者が Google アカウントでログインして許可した範囲で、YouTube API サービスを通じて次のことだけを行います。

  • 利用者の YouTube チャンネルへの動画のアップロード
  • 利用者のチャンネルと動画の情報、および再生数などの統計の読み取り

保存と共有

ログインの情報と読み取った統計は、利用者本人のパソコンにだけ保存します。外部のサーバーには送らず、第三者に提供・販売することはありません。

Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

アクセスの取り消し

本ツールへのアクセス権は、Google アカウントのサードパーティ製のアプリとサービスからいつでも取り消せます。

関連する規約

本ツールは YouTube API サービスを使っています。利用者は YouTube 利用規約に従うものとし、Google によるデータの扱いは Google プライバシー ポリシーに定められています。
